# Production-ready walking slice

A user can sign in by email OTP, discover Livepeer offers, create an immutable quoted workload and one-time Python SDK token, run through the remote signer, and inspect attributed usage and both quote-derived and signer-reported cost. Google/GitHub may be enabled independently. An administrator signs in with the configured email, inspects users/workloads/usage, and controls a global authorization stop.

The default deployment uses four services and durable SQLite/Redpanda/signer volumes. It includes no commercial billing, ledger, organization tenancy, invitation, dynamic adapter loading, OpenMeter, Stripe, Auth0, Turnkey, or go-livepeer patch.

The UX retains the validated Pymthouse-derived information density, navigation model, dark zinc/emerald language, responsive shell, semantic markup, global CSS control, and Shadow Part contract.
